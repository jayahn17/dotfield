## 10. Proof gates and tests

**Gate order in `render`** (atomic; first blocking failure stops with exit 2 and a receipt listing every check that ran): schema → topology (incl. fields budget) → privacy (HMAC stamp, viewer exclusion, foreign bodies, absolute paths, taint) → layout (overlap, clearance, route-through-node, containment, pose precedence, series collision, determinism) → render (hex literals, external refs, SRI, size budget, disabled views, self-view export) → receipt. `share project` runs schema → share → receipt; `run` runs `DF_RUN_ROUTE_PARITY`, `DF_RUN_NO_CHALLENGER`, `DF_RUN_BUDGET_EXCEEDED`, `DF_RUN_WRITE_BEFORE_APPROVAL`, `DF_RUN_FOREIGN_UNFENCED`. Every code lives once in `lib/rules.mjs` with a repair sentence; `scripts/gen-rules-md.mjs` writes `references/RULES.md`; `test/rules.test.js` asserts every code any gate can emit exists and is raised by at least one fixture.

Rule families: `DF_SCHEMA_*`, `DF_ROOM_*` (…, `MATURITY_UNPROVEN`, `MATURITY_OVERCLAIM`, `PROOF_COMMAND_FORBIDDEN`), `DF_RECORD_*` (per-row import checks), `DF_IR_*`, `DF_PRIVACY_*`, `DF_LAYOUT_*`, `DF_RENDER_*`, `DF_STORE_*` (`SCOPE_REFUSED`, `SCOPE_EMPTY_UID`, `FAULT`, `WRITE_WITHOUT_APPROVAL`, `MAX_RECORDS`, `MAX_BYTES`, `ENV_PIN_IGNORED`), `DF_PROPOSAL_ALREADY_DECIDED`, `DF_APPROVE_NOT_OWNER`, `DF_SERVER_DECIDE_REFUSED`, `DF_SHARE_*`, `DF_OVERLAY_*` (`BAD_SIGNATURE`, `KEY_UNKNOWN`, `WRONG_RECEIVER`, `ID_NOT_NAMESPACED`, `OVERWRITES_LOCAL`, `GROUP_UNDECLARED`, `LINK_TARGET_NOT_BOUNDARY`, `LINK_DROPPED`, `EXPIRED`), `DF_IMPORT_UNSUPPORTED_DIAGRAM_TYPE`, `DF_SANDBOX_*`, `DF_RUN_*`, `DF_RECEIPT_*`, `DF_STRUCT_*`, `DF_PACK_DRAFT`, `DF_ENGINE_MODIFIED`, `DF_THEME_CONTRAST`, `DF_PROVIDER_UNAVAILABLE`, `DF_MCP_SDK_MISSING`.

**Browser evidence** is not in CI. `scripts/evidence.mjs` is opt-in: a Claude Code browser session for 2D/3D, or `--device adb` which pulls `adb exec-out screencap -p` from a Quest reached via `adb reverse tcp:4100 tcp:4100` (127.0.0.1 on the headset is a secure context; `recipes/vr-on-quest.md`). Without it every render receipt says `not_captured` and the SKILL report says **provisional**.

**CI** (`.github/workflows/dotfield.yml`, inside the folder; Node 22 and 24): `npm ci`, `node scripts/fetch-vendor.mjs`, `npm test`, `validate all --json`, `prove all --json`, render every example and pack example with `--json`, render twice under `SOURCE_DATE_EPOCH` and diff bytes, `node --check` over `bin lib renderers server mcp importers scripts test`, `npm run manifest` with an empty diff, `scripts/pack-init-check.mjs` (every shipped pack instantiates; with `DOTFIELD_TEMPLATE_REPO=1` the template tracks no `center/`), `init --pack starter` on a fresh clone, `doctor --json` with no keys, `scripts/subtree-check.mjs`, `scripts/demo-two-centers.sh` with `DOTFIELD_OWNER_TOKEN_FILE` set explicitly. Every receipt is uploaded as an artifact. Until the split, the owner may add a root-level son workflow that runs `cd dotfield && npm test` (one new file, no edits); it is not added by the template build itself.
